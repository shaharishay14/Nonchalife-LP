# Nonchalife

Marketing site for nonchalife.com. Run it with `npm install && npm run dev`, then open http://localhost:3000.

Set `NEXT_PUBLIC_APP_STORE_URL` (in Vercel, then redeploy) to turn the "Coming soon to iPhone" pills into App Store links.

App screenshots live in `public/screens/` (`today.png`, `activity.png`, `activity-dark.png`, `timer.png`). They are neutral placeholders for now; replace them with real 1170x2532 screenshots, same file names.
