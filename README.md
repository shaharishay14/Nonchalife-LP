# Nonchalife

Marketing site for nonchalife.com. Run it with `npm install && npm run dev`, then open http://localhost:3000.

The App Store link is set in `lib/config.ts`.

App screenshots live in `public/screens/` as 780x1688 PNGs (twice the 390x844 design size). Replace one by exporting the screen again under the same file name.
